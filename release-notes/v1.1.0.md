# Nine Men's Morris v1.1.0

This release turns the original portfolio build into a more accessible and
reviewable desktop game.

## Highlights

- Keyboard board navigation and visible focus indicators.
- High-contrast board mode plus shape markings for both player pieces.
- Versioned JSON save/resume with corrupt-save validation.
- Move-by-move visual review and copied match summaries.
- Draw-aware Hard AI and post-game match analysis.
- Responsive logical rendering verified at three common window sizes.

## Verification

- 79 automated tests.
- 97% branch coverage across the game and AI engines.
- Ruff, mypy, dependency auditing, Windows packaging, and startup smoke tests.
- Automated standard/high-contrast display matrix.
- Tag-triggered release builds with SHA-256 checksums and GitHub provenance.

## Known Limitations

- The portable executable is not code-signed and may trigger SmartScreen.
- 125% and 150% DPI captures are automated; final releases still require the
  documented manual Windows scaling check.
- An installer is intentionally deferred until the portable build has wider use.
