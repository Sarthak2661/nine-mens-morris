# Nine Men's Morris v1.0.0

The first portfolio release packages the complete desktop game as a portable
Windows executable. Python is not required to play.

## Highlights

- Complete placement, movement, capture, flying, win, and draw rules.
- Human-vs-human and human-vs-computer modes.
- Three distinct computer opponents:
  - Easy chooses random legal actions.
  - Normal completes mills and blocks immediate threats.
  - Hard uses deterministic depth-three minimax with alpha-beta pruning.
- Move-history export for review and debugging.
- Fresh interface screenshots and a 58-second demonstration video.

## Verification

- 58 automated tests.
- 98% branch coverage across the game and AI engines.
- Ruff formatting/linting and mypy type checks.
- Runtime dependency audit with no known vulnerabilities.
- Clean Windows GitHub runner build and executable startup smoke test.
- SHA-256 checksum included with the download.

## Download

Download `nine-mens-morris-windows-x64.exe` and optionally verify it against
`SHA256SUMS.txt`. The executable is portable and does not require an installer.

## Known Limitations

- The executable is not code-signed, so Windows SmartScreen may display a warning.
- Save creates move history; restoring a saved match is not implemented yet.
- Hard AI uses a fixed depth limit and is not a solved-game engine.
- Online multiplayer and an installer are not included in this release.
